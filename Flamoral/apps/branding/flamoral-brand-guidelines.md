## 1. Brand Essence

### What Flamoral Represents

Flamoral is the fusion of **flame** (passion, desire, warmth) and **floral** (beauty, growth, romance). Our brand embodies the spark of genuine human connection in a digital age.

We believe that meaningful relationships begin with authentic moments of attraction, nurtured through thoughtful interaction, and bloom into lasting connections.

### Brand Mission

*To ignite genuine connections that transform fleeting sparks into enduring flames of meaningful relationships.*

### Tone of Voice

| Attribute | Description | Example |
|-----------|-------------|---------|
| **Warm** | Inviting and approachable | "Ready to find your spark?" |
| **Confident** | Self-assured without arrogance | "You deserve someone extraordinary." |
| **Sophisticated** | Refined and tasteful | "Elevate your dating experience." |
| **Playful** | Light-hearted when appropriate | "Swipe right on adventure." |
| **Genuine** | Authentic and trustworthy | "Real people. Real connections." |

### Brand Keywords

```
Primary: Passion | Connection | Authenticity | Desire | Warmth
Secondary: Premium | Exclusive | Sophisticated | Confident | Alluring
Emotional: Excitement | Hope | Anticipation | Joy | Belonging
```

### Emotional Positioning

**Before Flamoral:** Uncertain, skeptical about online dating, overwhelmed by superficial apps
**With Flamoral:** Empowered, excited about possibilities, confident in finding quality matches
**After Flamoral:** Connected, fulfilled, grateful for meaningful relationship

### Brand Personality Spectrum

```
Conservative ●○○○○ Bold
Playful ○○●○○ Serious
Mass Market ○○○●○ Premium
Young ○○●○○ Mature
Digital ○●○○○ Human
```

## 2. Logo System

### 2.1 Primary Logo

The primary Flamoral logo combines the flame icon with the wordmark in a horizontal arrangement.

```
┌─────────────────────────────────────────┐
│                                         │
│    🔥  F L A M O R A L                 │
│   [icon]  [wordmark]                    │
│                                         │
└─────────────────────────────────────────┘
```

**Usage:** Hero sections, marketing materials, partnerships

### 2.2 Stacked Logo

Vertical arrangement with the icon above the wordmark.

```
┌─────────────┐
│             │
│     🔥      │
│   [icon]    │
│             │
│  FLAMORAL   │
│ [wordmark]  │
│             │
└─────────────┘
```

**Usage:** Square formats, app icons, social avatars

### 2.3 Icon-Only Version

The flame heart icon used independently.

```
┌───────┐
│       │
│  🔥   │
│       │
└───────┘
```

**Usage:** App icon, favicon, UI elements, loading states

### 2.4 Wordmark-Only Version

The Flamoral text without the icon.

```
┌─────────────────────┐
│                     │
│    F L A M O R A L  │
│                     │
└─────────────────────┘
```

**Usage:** In-app headers, footers, minimal contexts

### 2.5 Monochrome Versions

| Version | Usage | Background |
|---------|-------|------------|
| White | Dark backgrounds | #1A1A1A, dark imagery |
| Black | Light backgrounds | #FFFFFF, light imagery |
| Flame Red | Neutral backgrounds | #C4C4C4, patterns |

### 2.6 Clear Space Rules

Maintain minimum clear space equal to the height of the "F" in the wordmark (1x) on all sides.

```
┌─────────────────────────────────┐
│                                 │
│   ┌─1x─┐                       │
│   │    │                       │
│ 1x│ 🔥 FLAMORAL │1x            │
│   │    │                       │
│   └─1x─┘                       │
│                                 │
└─────────────────────────────────┘
```

### 2.7 Minimum Usage Sizes

| Format | Minimum Size |
|--------|--------------|
| Digital (Primary) | 120px width |
| Digital (Icon) | 24px |
| Print (Primary) | 30mm width |
| Print (Icon) | 8mm |

### 2.8 Recommended Placements

| Placement | Logo Version | Alignment |
|-----------|--------------|-----------|
| App Header | Icon + Wordmark | Center |
| Splash Screen | Stacked | Center |
| Marketing Banner | Primary | Left |
| Social Profile | Icon-Only | Center |
| Email Signature | Primary | Left |
| App Store | Icon-Only | Center |

### 2.9 Logo Don'ts

- Never stretch or distort the logo
- Never change the logo colors outside approved palette
- Never add effects (shadows, glows, 3D)
- Never rotate the logo
- Never place on busy backgrounds without contrast
- Never recreate or modify the flame icon

| richCharcoal on softIvory | 14.5:1 | AAA |
| softIvory on velvetWine | 7.8:1 | AAA |
| emberGold on richCharcoal | 6.1:1 | AA |

## 4. Typography

### 4.1 Typeface System

#### Heading Font: Playfair Display
A sophisticated serif that conveys elegance and premium quality.

```
Font: Playfair Display
Weights: Regular (400), Medium (500), Bold (700)
Style: Serif
Usage: Headlines, hero text, marketing copy
```

#### UI Font: Inter
A highly legible sans-serif optimized for digital interfaces.

```
Font: Inter
Weights: Regular (400), Medium (500), SemiBold (600), Bold (700)
Style: Sans-serif
Usage: Body text, UI elements, forms, navigation
```

## 5. Layout & Imagery

### 5.1 Spacing System

Base unit: **4px**

| Token | Value | Usage |
|-------|-------|-------|
| space-xs | 4px | Tight elements, icon padding |
| space-sm | 8px | Related elements, button padding |
| space-md | 16px | Standard spacing, card padding |
| space-lg | 24px | Section gaps, larger padding |
| space-xl | 32px | Major sections |
| space-2xl | 48px | Page sections |
| space-3xl | 64px | Hero spacing |
| space-4xl | 96px | Major page breaks |

### 5.2 Grid System

**Web:**
- 12-column grid
- Gutter: 24px
- Max width: 1280px
- Margins: 16px (mobile), 32px (tablet), 64px (desktop)

**Mobile:**
- 4-column grid
- Gutter: 16px
- Margins: 16px

### 5.3 Border Radius

| Token | Value | Usage |
|-------|-------|-------|
| radius-none | 0px | Sharp edges |
| radius-sm | 4px | Inputs, small buttons |
| radius-md | 8px | Cards, buttons |
| radius-lg | 16px | Large cards, modals |
| radius-xl | 24px | Featured elements |
| radius-full | 9999px | Pills, avatars |

### 5.4 Photo Style Guidelines

**Portrait Photography:**
- Natural lighting preferred
- Warm color grading (slight orange/amber lift)
- Authentic expressions (no stock photo smiles)
- Diverse representation
- High quality (minimum 2000px on longest edge)

**Image Treatment:**
```css
/* Standard profile photo overlay */
filter: contrast(1.02) saturate(1.05);

/* Premium profile highlight */
filter: contrast(1.05) saturate(1.1) brightness(1.02);
```

**Avoid:**
- Heavy filters
- Unnatural colors
- Low resolution imagery
- Overly posed shots
- Generic stock photography

### 5.5 Light vs Dark Mode

#### Light Mode
```
Background: softIvory (#FFF6EE)
Surface: #FFFFFF
Elevated Surface: #FFFFFF + shadow
Text Primary: richCharcoal (#1A1A1A)
Text Secondary: #666666
Accent: flameRed (#D62839)
```

#### Dark Mode
```
Background: richCharcoal (#1A1A1A)
Surface: #2A2A2A
Elevated Surface: #3A3A3A
Text Primary: softIvory (#FFF6EE)
Text Secondary: #AAAAAA
Accent: emberOrange (#FF6E35)
```

### 5.6 Shadows

| Level | Shadow | Usage |
|-------|--------|-------|
| Soft | `0 2px 8px rgba(26,26,26,0.08)` | Subtle elevation |
| Medium | `0 4px 16px rgba(26,26,26,0.12)` | Cards, buttons |
| Strong | `0 8px 32px rgba(26,26,26,0.16)` | Modals, dropdowns |
| Glow | `0 4px 24px rgba(214,40,57,0.3)` | Primary button hover |

## 7. Animation Guidelines

### 7.1 Timing Functions

```css
/* Standard ease - most interactions */
--ease-standard: cubic-bezier(0.4, 0, 0.2, 1);

/* Decelerate - elements entering */
--ease-decelerate: cubic-bezier(0, 0, 0.2, 1);

/* Accelerate - elements exiting */
--ease-accelerate: cubic-bezier(0.4, 0, 1, 1);

/* Spring - playful interactions */
--ease-spring: cubic-bezier(0.175, 0.885, 0.32, 1.275);
```

### 7.2 Duration Scale

| Token | Duration | Usage |
|-------|----------|-------|
| instant | 100ms | Color changes, opacity |
| fast | 200ms | Small elements, hover |
| normal | 300ms | Most transitions |
| slow | 400ms | Large elements, modals |
| glacial | 600ms | Page transitions |

### 7.3 Animation Principles

1. **Purpose:** Every animation should serve a purpose
2. **Subtlety:** Avoid jarring or excessive motion
3. **Consistency:** Same interactions = same animations
4. **Performance:** Use transforms and opacity only
5. **Accessibility:** Respect `prefers-reduced-motion`

### 7.4 Key Animations

**Button Press:**
```css
transform: scale(0.98);
transition: transform 100ms ease-standard;
```

**Card Hover:**
```css
transform: translateY(-4px);
box-shadow: 0 8px 32px rgba(26,26,26,0.16);
transition: all 200ms ease-decelerate;
```

**Like Heart:**
```css
@keyframes heartPop {
  0% { transform: scale(1); }
  50% { transform: scale(1.3); }
  100% { transform: scale(1); }
}
animation: heartPop 400ms ease-spring;
```

**Match Celebration:**
```css
@keyframes matchGlow {
  0% { opacity: 0; transform: scale(0.8); }
  50% { opacity: 1; transform: scale(1.1); }
  100% { opacity: 1; transform: scale(1); }
}
animation: matchGlow 600ms ease-spring;
```
