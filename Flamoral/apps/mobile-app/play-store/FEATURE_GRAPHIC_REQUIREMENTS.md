# Google Play Store Feature Graphic Requirements

## Feature Graphic Specifications

The feature graphic is displayed at the top of your app's store listing page.

### Technical Requirements

- **Dimensions**: 1024 x 500 pixels (exactly)
- **File Format**: PNG or JPEG (24-bit PNG recommended)
- **Maximum File Size**: 1 MB
- **Color Space**: sRGB
- **Transparency**: Not allowed (must have opaque background)

### Design Guidelines

1. **No Text Overlay**
   - Avoid placing important text in the graphic
   - Google Play may overlay badges, text, or buttons
   - Keep key visual elements centered

2. **Brand Colors**
   - Primary: #FF6B9D (Pink/Coral)
   - Secondary: #C73866 (Deep Rose)
   - Accent: #FFA5C0 (Light Pink)
   - Background: White or gradient

3. **Content Suggestions**
   - Flamoral logo prominently displayed
   - Tagline: "Where Passion Meets Connection"
   - Visual elements: Hearts, profiles, connections
   - Modern, clean, professional aesthetic
   - Represent diversity and inclusivity

4. **Safe Zones**
   - Keep important content within 924 x 400 px center area
   - 50 px padding on left/right
   - 50 px padding on top/bottom

### Design Elements to Include

- Flamoral branding/logo
- App tagline or key value proposition
- Visual metaphors for connection/dating
- Modern, vibrant color palette
- High-quality graphics (no pixelation)

### What to Avoid

- Generic stock photos
- Cluttered layouts
- Small or unreadable text
- Misleading imagery
- Sexually suggestive content
- Depictions of real people without permission
- Offensive or inappropriate imagery

## App Icon Requirements

### Technical Specifications

- **Dimensions**: 512 x 512 pixels (minimum)
- **File Format**: PNG (32-bit with alpha)
- **Maximum File Size**: 1 MB
- **Shape**: Square with rounded corners (applied by Android)

### Design Guidelines

1. **Simple & Memorable**
   - Clear visual at small sizes
   - Distinctive and recognizable
   - Consistent with brand identity

2. **Icon Content**
   - Flamoral "F" logo or flame symbol
   - Brand colors
   - No text (logo only)
   - Centered design

3. **Adaptive Icon**
   - Provide foreground and background layers
   - Foreground: 432 x 432 px safe zone
   - Background: Full 512 x 512 px

## Screenshots Requirements

### Phone Screenshots

- **Quantity**: 2 minimum, 8 maximum
- **Dimensions**:
  - Minimum: 320 px on shortest side
  - Maximum: 3840 px on longest side
  - Aspect Ratio: 16:9 or 9:16
  - Recommended: 1080 x 1920 px (portrait)

### Tablet Screenshots (Optional)

- **Quantity**: Up to 8
- **Dimensions**:
  - Minimum: 1024 px on shortest side
  - Recommended: 2048 x 2732 px

### Screenshot Content Suggestions

1. **Discovery/Swiping Screen**
   - Show profile cards with video preview
   - Demonstrate swipe interface
   - Highlight match percentage

2. **Profile Screen**
   - Video profile showcase
   - User information display
   - Verification badge

3. **Messaging Screen**
   - Clean conversation interface
   - Smart reply suggestions
   - Media sharing capabilities

4. **Matches Screen**
   - Grid of matches
   - Match notifications
   - Connection indicators

5. **Video Call Screen**
   - Video calling interface
   - Call controls
   - Safe, professional environment

6. **Safety Features**
   - Safety toolkit
   - Reporting options
   - Privacy controls

7. **Gamification**
   - Daily rewards
   - Achievements
   - Level progression

8. **AI Features**
   - Smart matching
   - Conversation starters
   - Personality insights

### Screenshot Design Guidelines

- Use real app screens (no mockups)
- Show actual UI elements
- Include status bar and navigation
- Use diverse representation in demo profiles
- Blur or use stock photos for user content
- Add captions/annotations if helpful
- Maintain consistent device frame
- Use light mode for clarity

## Promotional Video (Optional)

### Specifications

- **Length**: 30 seconds to 2 minutes
- **Format**: MPEG, AVI, WMV, FLV, or 3GPP
- **Resolution**: 1280 x 720 (720p) minimum
- **File Size**: Up to 100 MB

### Content Suggestions

- App walkthrough
- Key feature highlights
- User testimonials (with permission)
- Value proposition
- Call to action
