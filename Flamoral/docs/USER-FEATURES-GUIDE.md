## 👤 User Journey

### Phase 1: Getting Started

#### 1. **Create Account** ✅ (Implemented)
**What users can do:**
- Register with email and password
- Register with social login (Google, Apple, Facebook)
- Verify email/phone number
- Set up basic profile information

**Required Information:**
- Full name
- Date of birth (must be 18+)
- Gender identity
- Email address
- Password
- Phone number (optional)

**Current Status:** ✅ **READY** - Fully implemented and tested

#### 2. **Build Profile** 📋 (Next Phase)

## ❓ Frequently Asked Questions

### General

**Q: Is Flamoral free?**
A: Yes! Basic features are completely free. Premium tiers offer additional features.

**Q: Do I need to pay to message?**
A: No! Messaging is free for all matches.

**Q: How does matching work?**
A: Both users must like each other (mutual match) to unlock chat.

### Safety

**Q: Is my data safe?**
A: Yes. We use bank-level encryption and never share personal data.

**Q: Can I block someone?**
A: Yes, instantly. They won't know and can't contact you.

**Q: What if I feel unsafe?**
A: Use panic button, contact support, or local authorities immediately.

### Features

**Q: Can I undo a swipe?**
A: Yes, with Premium subscription (Rewind feature).

**Q: How do I get more matches?**
A: Complete profile, stay active, use Boost, improve photos.

**Q: Can I search for specific people?**
A: No, to protect privacy. Use discovery algorithm.
