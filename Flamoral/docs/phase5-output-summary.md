## Production Deployment Prerequisites

Before deploying to production:

1. **Repository Variables:**
   - Set `PROD_DEPLOY_ENABLED=true` to unlock production deployments

2. **Environment Protection:**
   - Configure `production-approval` environment with required reviewers
   - Configure `production` environment with deployment protection rules

3. **Secrets Required:**
   - `AZURE_CREDENTIALS`
   - `AZURE_CLIENT_ID`
   - `AZURE_CLIENT_SECRET`
   - `AZURE_TENANT_ID`
   - `AZURE_SUBSCRIPTION_ID`
   - `SLACK_WEBHOOK_URL`
   - `PROD_URL`
   - `PROD_API_URL`

4. **Release Process:**
   - Create release candidate tag (e.g., `rc-abc123`)
   - Ensure staging tests have passed
   - Trigger manual workflow dispatch
