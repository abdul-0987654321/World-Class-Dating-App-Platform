========================================
WHAT WAS FIXED
========================================

1. CSRF TOKEN HANDLING
   - Auto-fetches CSRF token on initialization from /auth/csrf-token
   - Automatically includes X-CSRF-Token header on all mutations (POST, PUT, PATCH, DELETE)
   - Auto-refreshes CSRF token on 403 errors with code CSRF_TOKEN_INVALID
   - Public methods: getCsrfToken(), refreshCsrfToken()

2. RETRY LOGIC FOR TRANSIENT FAILURES
   - Automatic retries for 503, 502, 500, 504, 429, 408 status codes
   - Network error handling (retries when no response)
   - Exponential backoff (1s, 2s, 4s, etc.)
   - Configurable: retries (default: 3), retryDelay (default: 1000ms)

3. ENHANCED ERROR HANDLING
   - 503 errors are automatically retried
   - Standardized ApiError interface with isRetryable flag
   - Global error handler via onError callback
   - Consistent error format across all requests

4. JWT TOKEN REFRESH LOGIC
   - Automatic token refresh on 401 errors
   - Request queueing during token refresh
   - Original request retry with new token
   - Fallback to onTokenExpired() if refresh fails
   - Prevents multiple simultaneous refresh calls

5. CONFIGURATION IMPROVEMENTS
   - withCredentials: true for CSRF cookies
   - Configurable timeout (default: 30 seconds)
   - New config options: retries, retryDelay, refreshToken

6. TYPESCRIPT IMPROVEMENTS
   - Created tsconfig.json with strict type checking
   - Enhanced type definitions
   - Better IntelliSense support

========================================
USAGE EXAMPLE
========================================

// Initialize with all new features
initApiClient({
  baseURL: 'https://api.flamoral.com',
  timeout: 30000,
  retries: 3,
  retryDelay: 1000,

  getToken: () => localStorage.getItem('token'),

  refreshToken: async () => {
    const response = await fetch('/auth/refresh', {
      method: 'POST',
      credentials: 'include'
    });
    const { token } = await response.json();
    localStorage.setItem('token', token);
    return token;
  },

  onTokenExpired: () => {
    localStorage.removeItem('token');
    window.location.href = '/login';
  },

  onError: (error) => {
    console.error('API Error:', error);
    if (error.status === 503) {
      showToast('Service temporarily unavailable');
    }
  }
});
