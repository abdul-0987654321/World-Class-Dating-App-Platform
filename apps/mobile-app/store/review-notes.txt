FEATURES REQUIRING SPECIAL SETUP
================================================================================

1. LOCATION SERVICES
   - Location permission is required for the discovery/matching feature
   - If denied, users can still browse but with limited functionality
   - The app uses coarse location only (city-level)
   - Test accounts have been configured with sample locations

2. CAMERA ACCESS
   - Required for: Profile photo capture, Video profile recording
   - Required for: Photo verification process
   - Required for: Video calling with matches
   - If denied, users can still upload photos from gallery

3. PUSH NOTIFICATIONS
   - Used for: New matches, new messages, likes received
   - Optional but recommended for best experience
   - Users can configure notification preferences in Settings

4. PHOTO VERIFICATION
   - Users are prompted to verify their photos using a selfie
   - AI compares selfie with profile photos for authenticity
   - Test accounts are pre-verified

5. IN-APP PURCHASES
   - Subscription tiers: Premium, Gold, Platinum
   - Consumables: Coins, Boosts, Super Likes
   - Use sandbox/test accounts for purchase testing
   - All IAP products are configured in App Store Connect / Play Console

6. VIDEO CALLING
   - Uses Agora SDK for real-time video
   - Requires camera and microphone permissions
   - Only available between matched users
   - Test by matching two demo accounts and initiating call

7. AGE VERIFICATION
   - App requires users to be 18+ years old
   - Date of birth is collected during registration
   - Users under 18 are not permitted to create accounts
