## Login Problems

### Can't Log In - "Invalid Credentials"

**Solutions:**
1. **Verify your email/password**
   - Check for typos
   - Ensure caps lock is off
   - Try copying and pasting credentials

2. **Reset your password**
   - Tap "Forgot Password?" on login screen
   - Enter your registered email
   - Check email for reset link (check spam folder)
   - Create new password
   - Try logging in again

3. **Verify login method**
   - If you signed up with Google/Facebook/Apple, use that method
   - Don't try email/password if you used social login

4. **Check account status**
   - Your account may have been suspended or deleted
   - Contact support@flamoral.com for account status

### "Account Not Found"

**Possible causes:**
- Account was deleted
- Using wrong email address
- Account was banned for violations

**Solutions:**
1. Try all email addresses you might have used
2. Check if you used social login instead
3. Contact support@flamoral.com with details

### Social Login Not Working

**For Google Login:**
1. Update Google app to latest version
2. Clear Google app cache
3. Re-authorize Flamoral in Google settings
4. Try logging out and back into Google account

**For Facebook Login:**
1. Update Facebook app
2. Check Facebook app permissions for Flamoral
3. Re-authorize in Facebook settings
4. Log out and back into Facebook

**For Apple Login (iOS):**
1. Go to Settings > [Your Name] > Password & Security
2. Check apps using Apple ID
3. Ensure Flamoral is authorized
4. Update iOS to latest version

### Two-Factor Authentication Issues

**If you enabled 2FA and can't receive codes:**
1. **SMS codes not arriving:**
   - Check signal strength
   - Verify phone number is correct in settings
   - Try "Resend Code"
   - Wait up to 5 minutes
   - Contact your carrier about SMS blocking

2. **Authenticator app codes not working:**
   - Ensure device time is synced correctly
   - Generate new code (they expire every 30 seconds)
   - Try backup codes (saved when you set up 2FA)
   - Contact support if you lost backup codes

### App Says "Session Expired"

**Solutions:**
1. Simply log in again
2. If persistent:
   - Clear app cache
   - Log out completely
   - Close and reopen app
   - Log back in

## Match Issues

### Not Getting Any Matches

**Common causes and solutions:**

1. **Incomplete Profile**
   - Add 6-9 high-quality photos
   - Write detailed bio (200+ characters)
   - Fill out all profile sections
   - Verify your profile

2. **Too Restrictive Filters**
   - Increase age range
   - Expand distance radius
   - Remove advanced filters temporarily
   - Check if you accidentally set incompatible preferences

3. **Not Active Enough**
   - Swipe daily (algorithm favors active users)
   - Log in during peak hours (6-9 PM)
   - Complete your daily swipes
   - Engage with Top Picks

4. **Profile Quality Issues**
   - Use clear, recent photos
   - Smile in at least one photo
   - Avoid group photos where you can't be identified
   - Remove low-quality or blurry photos
   - Get feedback from friends

5. **Location Issues**
   - Ensure location services are enabled
   - Check if you're in a low-population area
   - Consider using Passport mode (Premium) to try other cities
   - Verify correct city is showing on profile

**Quick fixes:**
- Run a Profile Boost during peak hours
- Update your main photo
- Refresh your bio
- Get profile verification badge

### Matches Disappearing

**Why matches disappear:**
1. **They unmatched you** - Most common reason
2. **They deleted their account**
3. **Their account was banned** - Violated community guidelines
4. **Technical glitch** - Rare, but possible

**What to do:**
- Unfortunately, you can't restore unmatched connections
- Move on to new matches
- If many matches disappear suddenly, contact support

### Match Notification But Can't Find Match

**Solutions:**
1. Refresh the Matches tab (pull down to refresh)
2. Check if they already unmatched
3. Look in "Recently Active" section
4. Search by name if you remember it
5. Close and reopen app
6. Update app to latest version

### Can't Swipe - "No One New Around You"

**Solutions:**
1. **Expand search radius**
   - Settings > Discovery Preferences > Distance
   - Increase maximum distance

2. **Adjust age range**
   - Expand age range in discovery preferences

3. **Wait for new users**
   - Check back in a few hours
   - More users join during evenings/weekends

4. **You've swiped on everyone in your area**
   - Try Passport mode to swipe in new locations
   - Wait for new users to join
   - Expand your filters

5. **Account may be shadow-banned**
   - If you were reported multiple times
   - Contact support to check account status

## Messaging Problems

### Messages Not Sending

**Immediate checks:**
1. Verify internet connection (try toggling WiFi/cellular)
2. Check if conversation still exists (they may have unmatched)
3. Verify you weren't blocked

**Solutions:**
1. **Close and reopen conversation**
2. **Force close and restart app**
3. **Check for app updates**
4. **Clear app cache:**
   - iOS: Offload app, then reinstall
   - Android: Settings > Apps > Flamoral > Clear Cache
5. **Try sending from web version** (flamoral.com)

### Messages Sent But Not Delivered

**Possible causes:**
- Poor internet connection (message queued)
- Server delay (rare)
- They unmatched during sending

**Wait 5 minutes and check if:**
- Message shows "Sent" status
- If still pending, close and reopen app
- If failed, try resending

### Can't See Read Receipts (Premium Users)

**Verify:**
1. You have active Premium subscription
2. Read receipts are enabled in settings
3. The other person opened the message (may take time)

**Note:** Read receipts only work if:
- You sent the message after subscribing to Premium
- The recipient opened the message after you got Premium

### Photos Won't Send in Messages

**Solutions:**
1. **Check photo size** - Must be under 10MB
2. **Check format** - JPG, PNG, or HEIC only
3. **Compress large photos:**
   - iOS: Use "Share > Mail > Resize" before sending
   - Android: Use photo compression app
4. **Verify permissions:**
   - Settings > Flamoral > Photos > Allow Access
5. **Try different photo**
6. **Clear app cache**

### Voice Messages Not Working

**Check:**
1. **Microphone permissions:**
   - Settings > Flamoral > Microphone > Allow
2. **Environment is not too loud**
3. **Hold microphone button while recording**
4. **Maximum 60 seconds per voice message**

**If still not working:**
- Test microphone in other apps
- Restart device
- Reinstall app

### Typing Indicator Not Showing

**This is normal behavior:**
- Typing indicators are delayed by 2-3 seconds
- They don't appear if person stops typing quickly
- Both users must have good internet connection

**Not a Premium feature** - All users see typing indicators

## Payment Failures

### Subscription Payment Failed

**Common causes:**

1. **Insufficient funds**
   - Check bank account balance
   - Verify credit card isn't maxed out

2. **Expired card**
   - Update payment method
   - Remove old card, add new one

3. **Bank declined transaction**
   - Contact your bank (they may flag as suspicious)
   - Approve the charge
   - Try again

4. **Wrong billing information**
   - Verify billing address matches card
   - Check ZIP code is correct

**How to fix:**
1. **Update payment method:**
   - iOS: Settings > [Your Name] > Payment & Shipping
   - Android: Google Play > Payment Methods
   - Web: Flamoral.com > Settings > Subscription

2. **Try different payment method**
3. **Contact your bank** to approve charges from Flamoral/Stripe
4. **Try again in 24 hours** if temporary issue

### Charged But Features Not Unlocked

**Solutions:**
1. **Force close and reopen app** (takes up to 5 minutes)
2. **Log out and log back in**
3. **Check subscription status:**
   - iOS: Settings > Subscriptions
   - Android: Play Store > Subscriptions
   - Web: Flamoral.com > Settings

4. **Verify purchase receipt:**
   - Check email for confirmation
   - Ensure payment processed successfully

5. **Restore purchases:**
   - iOS: Profile > Settings > Restore Purchases
   - Android: Profile > Settings > Restore Purchases

6. **If still not working after 30 minutes:**
   - Contact support@flamoral.com
   - Include receipt/transaction ID

### Charged Twice for Same Subscription

**Possible causes:**
- Subscription renewed before cancellation processed
- Charged on different payment methods
- Subscribed on multiple platforms (iOS + Android + Web)

**Solutions:**
1. **Check all your payment methods**
2. **Verify subscription on all platforms:**
   - Apple Subscriptions
   - Google Play Subscriptions
   - Flamoral web account

3. **Contact support for refund:**
   - Email support@flamoral.com
   - Include both transaction IDs
   - Explain duplicate charge
   - Refund processed in 5-7 business days

### Can't Cancel Subscription

**By platform:**

**iOS:**
- Must cancel through Apple Subscriptions, not Flamoral app
- Settings > [Your Name] > Subscriptions > Flamoral

**Android:**
- Must cancel through Google Play, not Flamoral app
- Play Store > Menu > Subscriptions > Flamoral

**Web:**
- Flamoral.com > Profile > Settings > Subscription > Cancel

**Common issues:**
- Looking in wrong place (must cancel through platform)
- Subscription already canceled
- Trying to cancel too close to renewal (wait 24 hours after renewal)

## App Performance Issues

### App Crashing Frequently

**Solutions (in order):**

1. **Force close app completely**
   - iOS: Swipe up from bottom, swipe app away
   - Android: Recent Apps > Swipe Flamoral away

2. **Restart device**

3. **Update app to latest version**
   - App Store (iOS) or Play Store (Android)
   - Check for updates

4. **Clear app cache:**
   - iOS: Settings > General > iPhone Storage > Flamoral > Offload App > Reinstall
   - Android: Settings > Apps > Flamoral > Storage > Clear Cache

5. **Free up device storage**
   - Delete unused apps
   - Clear photos/videos
   - Need at least 1GB free space

6. **Uninstall and reinstall app**
   - Delete app
   - Restart device
   - Reinstall from store
   - Log back in

7. **Check for OS updates**
   - Update iOS or Android to latest version

**If crashes persist:**
- Contact support@flamoral.com
- Include: Device model, OS version, when crashes occur

### App Running Slow/Laggy

**Quick fixes:**
1. Close other apps running in background
2. Restart app
3. Restart device
4. Clear app cache
5. Update app

**Long-term solutions:**
1. **Free up RAM:**
   - Close unused apps
   - Restart device regularly

2. **Free up storage:**
   - Need 1GB+ free space
   - Delete old photos/videos

3. **Check internet speed:**
   - Need at least 3 Mbps for smooth experience
   - Switch between WiFi and cellular
   - Reset router

4. **Update device OS**

5. **Reinstall app**

### Swiping is Laggy or Unresponsive

**Solutions:**
1. Close and reopen app
2. Clear app cache
3. Reduce animations:
   - iOS: Settings > Accessibility > Motion > Reduce Motion
   - Android: Settings > Accessibility > Remove Animations

4. Ensure good internet connection
5. Update app
6. Restart device

### Photos Loading Slowly

**Causes:**
- Slow internet connection
- Server issues (rare)
- Too many apps using network

**Solutions:**
1. **Check internet speed** (need 3+ Mbps)
2. **Switch networks** (WiFi to cellular or vice versa)
3. **Close other apps** using bandwidth
4. **Wait a few seconds** for high-res version to load
5. **Clear app cache**

## Photo Upload Issues

### Photos Won't Upload

**Common solutions:**

1. **Check photo permissions:**
   - iOS: Settings > Flamoral > Photos > All Photos
   - Android: Settings > Apps > Flamoral > Permissions > Storage

2. **Verify photo requirements:**
   - Format: JPG, PNG, or HEIC
   - Size: Under 10MB
   - Dimensions: At least 800x800 pixels

3. **Compress large photos:**
   - Use photo editing app to reduce size
   - Save as JPG with 80% quality

4. **Check internet connection:**
   - Need stable connection for uploads
   - Try WiFi instead of cellular

5. **Clear app cache and try again**

6. **Try different photo**
   - Issue may be with specific file

### "Photo Rejected" Error

**Reasons photos are rejected:**
1. **Inappropriate content** (nudity, violence)
2. **Not a photo of a person**
3. **Blurry or low quality**
4. **Contains children** (unless clearly yours and you're in photo)
5. **Copyrighted image**
6. **Meme or screenshot**
7. **No face visible**

**Solutions:**
- Upload different photo
- Ensure it meets community guidelines
- Use recent, clear photos of yourself
- If you believe rejection was an error, contact support

### Photos Appearing Blurry

**Causes:**
- Photo was low resolution
- Photo was compressed during upload
- Internet connection interrupted upload

**Solutions:**
1. **Re-upload in higher quality:**
   - Use original photo, not screenshot
   - Ensure at least 1080x1080 resolution
   - Upload via WiFi for best quality

2. **Check original photo quality**
3. **Take new photos** with better camera quality

### Can't Delete Photos

**Solutions:**
1. Go to Edit Profile
2. Tap X on photo you want to remove
3. Ensure you keep minimum 2 photos (can't delete if only 2 left)
4. Save changes
5. If still not working, try web version

## Notification Problems

### Not Receiving Notifications

**Check notification settings (both must be enabled):**

**iOS:**
1. Device Settings > Notifications > Flamoral
2. Enable "Allow Notifications"
3. Select alert style
4. Enable sounds/badges

**Android:**
1. Device Settings > Apps > Flamoral > Notifications
2. Enable all notification types

**In-app:**
1. Flamoral > Profile > Settings > Notifications
2. Enable desired notification types:
   - New matches
   - New messages
   - Likes
   - Super Likes

**Other causes:**
- Do Not Disturb mode enabled
- Battery saver mode blocking notifications
- App needs to run in background
- Notifications muted for specific conversations

**Solutions:**
1. Disable Do Not Disturb
2. Allow background app refresh:
   - iOS: Settings > General > Background App Refresh > Flamoral
   - Android: Settings > Apps > Flamoral > Battery > Unrestricted

3. Log out and log back in
4. Reinstall app

### Getting Too Many Notifications

**Customize what you receive:**
1. Profile > Settings > Notifications
2. Disable unwanted notification types:
   - New matches (keep)
   - Messages (keep)
   - Likes (optional)
   - Marketing (optional)
   - Daily Top Picks (optional)

3. **Mute specific conversations:**
   - Open conversation
   - Tap menu (three dots)
   - Tap "Mute Notifications"

### Notification Delays

**Causes:**
- Battery optimization limiting background activity
- Poor internet connection
- Server delay (rare)

**Solutions:**
1. **Disable battery optimization:**
   - Android: Settings > Apps > Flamoral > Battery > Unrestricted
   - iOS: Settings > Battery > turn off Low Power Mode

2. **Enable background refresh**
3. **Keep app running in background** (don't force close)
4. **Ensure good internet connection**

## Video Call Issues

### Can't Make Video Calls

**Check requirements:**
- Both users must have video calling enabled
- Need strong internet (at least 5 Mbps)
- Camera and microphone permissions enabled

**Enable permissions:**
- iOS: Settings > Flamoral > Camera/Microphone > Allow
- Android: Settings > Apps > Flamoral > Permissions > Camera/Microphone

**Other solutions:**
1. Update app to latest version
2. Restart app
3. Test camera in other apps
4. Switch networks (WiFi/cellular)
5. Ensure match hasn't blocked video calls

### Poor Video Quality

**Solutions:**
1. **Improve internet connection:**
   - Need 5+ Mbps for HD video
   - Move closer to WiFi router
   - Switch to WiFi from cellular (or vice versa)
   - Close other apps using bandwidth

2. **Reduce network load:**
   - Pause downloads
   - Ask others to stop streaming on same network

3. **Check device performance:**
   - Close background apps
   - Restart device if overheating

4. **Lighting:**
   - Poor lighting makes video grainy
   - Ensure good lighting on your face

### Audio Problems During Calls

**Can't hear them:**
1. Check volume level
2. Disable silent/mute mode
3. Test with earphones
4. Check if Bluetooth is connecting audio elsewhere

**They can't hear you:**
1. Check microphone isn't muted (icon in call)
2. Remove phone case if blocking microphone
3. Test microphone in voice memo app
4. Grant microphone permissions

**Echo or feedback:**
1. Use earphones/headphones
2. Reduce volume
3. Ensure only one device is making sound

### Video Call Keeps Disconnecting

**Causes:**
- Unstable internet connection
- Low battery triggering power saving
- Call duration limit (none on Flamoral)

**Solutions:**
1. **Stabilize connection:**
   - Switch to WiFi
   - Move closer to router
   - Reset router

2. **Charge device** (above 20%)

3. **Close background apps**

4. **Update app**

5. **If persistent, try again later** (may be temporary server issue)

## Account Issues

### Account Suspended or Banned

**Why accounts get banned:**
- Violated community guidelines
- Inappropriate content or behavior
- Multiple user reports
- Spam or scam activity
- Harassment
- Underage (under 18)
- Fake profile

**What to do:**
1. Check email for suspension notice (explains reason)
2. If temporary suspension, wait for specified period
3. If permanent ban and you believe it's an error:
   - Contact appeals@flamoral.com
   - Explain situation
   - Provide evidence if available
4. Review our Community Guidelines
5. If ban is valid, you cannot create new account

### Can't Verify Profile

**Common issues:**

1. **Photo doesn't match profile photos:**
   - Use current, unfiltered selfie
   - Match your appearance in profile photos
   - Remove sunglasses, hats

2. **Poor selfie quality:**
   - Use good lighting
   - Face camera directly
   - Follow on-screen instructions exactly
   - Don't use someone else's photo

3. **Verification rejected:**
   - Try again with clearer photo
   - Ensure face is fully visible
   - Use same hairstyle/look as profile photos

4. **Technical error:**
   - Update app
   - Try again in 24 hours
   - Contact support if repeatedly fails

### Shadow Ban - Profile Not Being Shown

**Signs of shadow ban:**
- Suddenly no matches
- No one viewing profile
- Likes don't turn into matches

**Causes:**
- Multiple user reports
- Suspicious activity
- Profile guideline violations

**What to do:**
1. Review Community Guidelines
2. Remove any inappropriate content
3. Stop any spammy behavior
4. Wait 7-14 days
5. If persists beyond 2 weeks, contact support
6. Improve profile quality

### Data Export Request

**To export your data (GDPR/CCPA):**
1. Profile > Settings > Privacy
2. Tap "Download My Data"
3. Confirm request
4. Receive email with download link within 48 hours
5. Download includes:
   - Profile information
   - Messages
   - Match history
   - Photos
   - Activity logs

## Still Need Help?

### Contact Support

**Email:** support@flamoral.com

**Response times:**
- Free users: 24-48 hours
- Premium users: 12-24 hours
- Premium+ users: 4-8 hours

**Include in your message:**
- User ID or registered email
- Device (iPhone 14, Samsung Galaxy S23, etc.)
- OS version (iOS 17.2, Android 14, etc.)
- App version (Settings > About)
- Detailed description of problem
- Screenshots (if applicable)
- Steps to reproduce issue

### Before Contacting Support

Try these general fixes:
1. Update app to latest version
2. Restart app
3. Restart device
4. Clear app cache
5. Check internet connection
6. Verify account status
7. Read relevant sections of this guide

### Report a Bug

If you found a bug:
1. Note exact steps to reproduce
2. Take screenshots
3. Note device and app version
4. Email bugs@flamoral.com
