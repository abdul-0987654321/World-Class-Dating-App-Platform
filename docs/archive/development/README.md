# Development Documentation

Developer guides and workflows for the Flamoral platform.

## Contents

- [development-inventory.md](./development-inventory.md) - Development resources inventory

## Getting Started

1. Clone the repository
2. Install dependencies: `yarn install`
3. Set up environment variables (see `.env.example`)
4. Run services: `yarn dev`

## Tech Stack

- **Backend**: Node.js, Express, NestJS, Go
- **Frontend**: React, Vite, React Native
- **Database**: PostgreSQL, Cosmos DB, Redis
- **Infrastructure**: Azure (AKS, Terraform)

## Code Style

- TypeScript for all services
- ESLint + Prettier for formatting
- Jest for testing
