# FLAMORAL Platform - Subscription Entitlements Matrix

This document defines the complete feature entitlements for FLAMORAL's 6-tier subscription model. All feature access is enforced server-side to prevent client-side bypasses.

## Billing & Subscription Management

### Billing Cycles

- **Monthly**: Full price, cancel anytime
- **3 Months**: 10% discount, billed quarterly
- **6 Months**: 15% discount, billed bi-annually
- **Yearly**: 20% discount, billed annually

### Grace Period

- **Duration**: 3 days after failed payment
- **Access**: Full tier features retained during grace period
- **Notification**: Email + in-app notification on day 1, 2, and 3

### Downgrade Policy

- Immediate downgrade available
- Prorated refund for unused time (yearly subscriptions only)
- Features downgrade at end of current billing period

### Upgrade Policy

- Immediate access to new tier features
- Prorated billing for remaining period
- Auto-renewal at new tier price

## API Enforcement

### Tier Validation

```typescript
// All tier checks happen server-side
import { requireTier, requireFeature } from '@flamoral/backend-shared';

// Route-level tier requirement
router.get('/video-call', requireTier('premium'), videoCallHandler);

// Feature-level requirement
router.post('/super-like', requireFeature('super_likes_unlimited'), superLikeHandler);
```
