   Input: { token: string }
   Success: 200 - Email verified
   Errors: 400 - Invalid/expired token

2. POST /api/auth/resend-verification
   Input: { email: string }
   Success: 200 - Email sent
   Errors: 400 - Invalid email/already verified

3. POST /api/auth/reset-password
   Input: { token: string, newPassword: string }
   Success: 200 - Password reset
   Errors: 400 - Invalid token/weak password

4. POST /api/auth/validate-token
   Headers: { x-service-key: string }
   Input: { token: string }
   Success: 200 - Token valid with user data
   Errors: 401 - Invalid service key
           400 - Missing token
           500 - Invalid/blacklisted token
